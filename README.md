# Lehrraum

Die Lehrkraft-App der Unterrichtsplattform [kt-gymbruvi.github.io](https://kt-gymbruvi.github.io/): eine digitale Tafel
für Smartboard, iPad und PC. Tafelbilder werden nur auf dem eigenen Gerät gespeichert.

```
npm install
npm run dev      # http://localhost:5173/Lehrraum/
npm test
npm run build
```
